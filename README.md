# Kami-Linux-Software


- ⭐️⭐️超おすすめ
- ⭐️　 おすすめ（実用性が高い）
- `Proprietary`       
開発元が独占的に所有・管理しているソフトウェアや技術
ソースコードは公開されず、改変・再配布に制限がある。
プロプライエタリだから危険、オープンソースだから安全というわけではないです。








## 動画・音声・メディア

- [VLC media player](https://www.videolan.org/vlc/) - オープンソース。多数の動画・音声形式に対応した定番メディアプレーヤー。
- [Audacity](https://www.audacityteam.org/) - オープンソース。録音、カット、ノイズ除去、音声編集に対応したソフト。
- [Shotcut](https://shotcut.org/) - オープンソース。動画のカット、編集、エンコードに対応した動画編集ソフト。
- [LilyPond](https://lilypond.org/) - オープンソース。テキストで楽譜を記述し、美しい楽譜を生成できるソフト。

## RSS・ニュース・掲示板

- [Liferea](https://lzone.de/liferea/) - オープンソース。Linux向けのRSSフィードリーダー。
- [NewsFlash](https://gitlab.com/news-flash/news_flash_gtk) - オープンソース。GNOME向けのRSSリーダー。
- [Miniflux](https://miniflux.app/) - オープンソース。シンプルなWeb型RSSリーダー。
- [Fluent Reader](https://hyliu.me/fluent-reader/) - オープンソース。見やすいインターフェースのRSSリーダー。
- [Siki](https://sikiapp.net/) `Proprietary` - 5chなどの掲示板を閲覧・書き込みできる専用ブラウザー。

## Webブラウザー

- [Helium](https://github.com/imputnet/helium) - オープンソース。Chromiumベースで、広告やトラッキングへの対策を重視したWebブラウザー。
- [Tor Browser](https://www.torproject.org/download/) - オープンソース。Torネットワークを利用してWebサイトへアクセスするブラウザー。
- [GrapheneOS](https://grapheneos.org/) - オープンソース。セキュリティとプライバシーを重視したAndroid向けOS。Linux用アプリではない。

## 学習・メモ・文書管理

- [Anki](https://apps.ankiweb.net/) - オープンソース。フラッシュカード方式の暗記・学習アプリ。AnkiWebによる同期にも対応。
- [Joplin](https://joplinapp.org/) - オープンソース。Markdown対応のメモ・ノートアプリ。タグ、添付ファイル、同期に対応。
- [Zotero](https://www.zotero.org/) - オープンソース。論文やWeb資料の収集、引用管理、参考文献リストの作成に使える。
- [Calibre](https://calibre-ebook.com/) - オープンソース。電子書籍の管理、形式変換、メタデータ編集、閲覧ができる。
- [Sigil](https://sigil-ebook.com/) - オープンソース。EPUB形式の電子書籍を作成・編集できる。

## Android関連

- [scrcpy](https://github.com/Genymobile/scrcpy) - オープンソース。Android端末の画面をPCに表示し、キーボードやマウスで操作できる。
- [Packet](https://github.com/nozwock/packet) - Android標準のQuick Shareを利用して、LinuxとAndroid間でファイルを送受信できる。Bluetoothと同じWi-Fiネットワークが必要。
- [Apktool](https://github.com/iBotPeaches/Apktool) - オープンソース。APKファイルの解析・再構築に使える開発者向けツール。

## ファイル管理・圧縮・転送

- [PeaZip](https://peazip.github.io/) - オープンソース。7z、ZIP、TAR、RARなど多数の圧縮形式に対応した圧縮・展開ソフト。
- [LocalSend](https://localsend.org/) - オープンソース。同じネットワーク内の端末間でファイルを送信できる。
- [KDE Connect](https://kdeconnect.kde.org/) - オープンソース。スマートフォンとPC間でファイル転送、通知同期、クリップボード共有などができる。


## ダウンロード・P2P

- [qBittorrent](https://www.qbittorrent.org/) - オープンソース。広告のないBitTorrentクライアント。RSS、検索、帯域制限などに対応。
- [Varia](https://github.com/giantpinkrobots/varia) - オープンソース。Aria2を利用したシンプルなダウンロードマネージャー。

## セキュリティ・暗号化

- [Bitwarden](https://bitwarden.com/) - オープンソース。パスワード、パスキー、カード情報などを管理できるパスワードマネージャー。
- [VeraCrypt](https://www.veracrypt.fr/) - オープンソース。ファイルコンテナーやドライブ全体を暗号化できる。
- [Cryptomator](https://cryptomator.org/) - オープンソース。クラウドストレージ上のファイルを暗号化できる。
- [KeePassXC](https://keepassxc.org/) - オープンソース。ローカルでパスワードを管理できるパスワードマネージャー。
- [GnuPG](https://gnupg.org/) - オープンソース。ファイルの暗号化や電子署名に使えるコマンドラインツール。
- [Portmaster](https://safing.io/) - オープンソース。アプリごとの通信制御、トラッカーや広告のブロックに対応。
- [Tor Browser](https://www.torproject.org/download/) - オープンソース。Tor経由で通信し、アクセス元を隠してWeb閲覧できる。

## メール

- [Betterbird](https://www.betterbird.eu/) - オープンソース。Mozilla Thunderbirdをベースに、検索やメール表示などを改善したメールクライアント。

## ツール

- [CopyClip](https://github.com/Walkercito/CopyClip) - オープンソース。軽量なクリップボード履歴管理ソフト。

## その他

- [Vorta](https://vorta.borgbase.com/) - オープンソース。BorgBackupを利用したバックアップ管理GUI。
- [BorgBackup](https://www.borgbackup.org/) - オープンソース。重複排除や暗号化に対応したバックアップツール。
- [Wine](https://www.winehq.org/) - オープンソース。WindowsアプリをLinux上で実行する互換レイヤー。


## ゲーム

- [Lutris](https://lutris.net/) - オープンソース。Steam、Wine、DOSBox、エミュレーターなどのゲームをまとめて管理できるランチャー。
- [Wine](https://www.winehq.org/) - オープンソース。Linux上でWindowsアプリを動かすための互換レイヤー。
- [Bottles](https://usebottles.com/) - オープンソース。Wine環境をゲーム用、アプリ用などに分けて管理できるGUIフロントエンド。
- [AntiMicroX](https://github.com/AntiMicroX/AntiMicroX) - オープンソース。ゲームパッドのボタンをキーボードやマウス操作に割り当てられる。
- [CDEmu](https://cdemu.sourceforge.io/legacy/) - オープンソース。ISOなどのディスクイメージを仮想ドライブとしてマウントできるWindows向けソフト。

## 開発・プログラミング

- [Codex](https://openai.com/codex/) `Proprietary` - コード生成やコード編集を支援するAI開発ツール。
- [VSCodium](https://vscodium.com/) - Visual Studio Codeをベースに、Microsoft独自のテレメトリなどを除いたビルド。
- [Emacs](https://www.gnu.org/software/emacs/) - オープンソース。拡張性が高く、エディターや開発環境として利用できる。
- [Docker](https://www.docker.com/) - コンテナ環境を構築・管理するためのプラットフォーム。Docker Desktopは`Proprietary`。
- [Apktool](https://github.com/iBotPeaches/Apktool) - オープンソース。AndroidアプリのAPKを解析・再構築する開発者向けツール。
- [Quickemu](https://github.com/quickemu-project/quickemu) - オープンソース。QEMU仮想マシンを簡単に作成・実行できるコマンドラインツール。
